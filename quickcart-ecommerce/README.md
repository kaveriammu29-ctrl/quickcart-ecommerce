# QuickCart E-Commerce Website

A responsive React shopping website demo built with React, Vite and CSS.

## Features
- Responsive product catalogue
- Search products by name or description
- Filter by category
- Sort by featured, price and rating
- Add products to cart and change quantities
- Remove items from cart
- Wishlist toggle
- Demo checkout message (no real payment is collected)

## Tech stack
- React
- Vite
- CSS
- Lucide React icons

## Run locally
1. Install Node.js.
2. Open this folder in VS Code.
3. Open the terminal and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL shown in the terminal.

## Notes
This is a student portfolio project. Checkout is a front-end demonstration only. It does not process payments or store orders.
